# Chat Tools

A small collection of Python tools for working with Twitch chat logs generated by AtomowyBot.

## Features

### TXT → Twitch JSON Converter

Converts raw `.txt` chat logs into a TwitchDownloader-compatible `.json` format.

Additional options:

* Generate a censored version of the chat.
* Generate a reactions file alongside the JSON output.

### Reaction Finder

Analyzes chat activity and attempts to find interesting or funny moments by looking for bursts of messages containing keywords such as:

* `xd`
* `KEKW`
* `cinema`

The tool is designed to automatically locate moments that may be worth reviewing or clipping.

### DC Detector

Detects potential stream interruptions (internet issues, disconnects, stream crashes, etc.) by analyzing bursts of messages containing keywords such as:

* `papa`
* `emojiAngry`
* `F5 POLICE`
* `halo`

The detector produces a ranked list of timestamps that are likely to correspond to stream outages.

## Example Workflow

1. Export a chat log from AtomowyBot (`.txt`).
2. Convert it into Twitch JSON format.
3. Open the generated JSON in TwitchDownloader or other compatible tools.
4. Run the reaction finder or DC detector to locate interesting moments automatically.

---

## Notes

These tools were created primarily for personal stream archiving and chat analysis workflows. The detection algorithms are heuristic-based and may occasionally produce false positives, especially during chat spam events.
